# Educational Slide Show Project

Учебное веб‑приложение «Слайд‑шоу» на чистом JavaScript. Проект создан для отработки работы с DOM, обработки событий, управления состоянием и базовой навигации по слайдам.

## Цель проекта

Реализовать простое слайд‑шоу с возможностью переключения слайдов вперёд/назад, автопрокруткой и индикацией текущего слайда. Проект подходит как пример для портфолио начинающего JavaScript‑разработчика.

## Возможности

- Переключение слайдов кнопками «Назад» / «Вперёд».
- Автопрокрутка слайдов с настраиваемым интервалом.
- Отображение номера текущего слайда и общего количества слайдов.
- Плавная визуальная смена контента (CSS‑переходы).
- Адаптивная вёрстка для мобильных и десктопных экранов.

## Стек технологий

- HTML5
- CSS3
- JavaScript (ES6+)
- > Примечание: в учебном проекте слайды реализованы как секции внутри `index.html`. Файл `index_slide_1.html` оставлен как пример модульного подхода и заготовки для масштабирования (например, под загрузку слайдов через AJAX или в React‑компонентах).
